# Sentinel AI — Flutter

Same product as the web app, ready for Android / iOS.

## Run

Install [Flutter](https://docs.flutter.dev/get-started/install), then:

```bash
cd sentinel_flutter
flutter pub get
flutter run
```

Open this folder in VS Code or Android Studio with the Flutter plugin.

Screens: splash, login, home (swipe stat cards), scan hub, link/SMS scanners, academy, notifications, more.
